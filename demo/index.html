DAA Algorithm Stress-Testing Lab

Scenario: a software assurance team wants to know not only whether an algorithm is correct, but when it becomes slow, memory-intensive or impractical. Pick an algorithm, then use Scenario to feed it a typical input and a carefully crafted one. Risk is classified Low / Moderate / High. Live in-browser ports of our Python algorithms.

The full Python framework also tests Binomial/Fibonacci heaps and B-Trees; this page covers trees, MST, knapsack, DP and backtracking / Branch & Bound.
